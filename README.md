# مكتب التداول اليدوي

## ما هو؟

مكتب تداول يعمل كله داخل جلسات كلود كود. ترفق لقطات شاشة من ميتاتريدر، وتكتب أمراً واحداً، فتحصل على تذكرة تنسخها بيدك إلى المنصة، أو على جواب واضح: لا صفقة، مع السبب.

لا يوجد تطبيق ولا خادم ولا روبوت. لا يتصل المشروع بأي خدمة خارجية، ولا يضع أي أمر، ولا يطلب كلمة مرور.

**للتدريب على حساب تجريبي فقط. ليست نصيحة مالية.**

## طريقة الاستخدام في خمسة أسطر

1. افتح المشروع في كلود كود.
2. حدّث بيانات الحساب: أرفق لقطة تبويب التداول، أو لقطة مواصفات الرمز، ثم اكتب:

```
/account
```

3. أرفق لقطات الشارت للرمز نفسه (الأفضل: أسبوعي وأربع ساعات وساعة، مع تبويب التداول)، ثم اكتب:

```
/trade
```

4. انسخ التذكرة إلى المنصة بيدك، أو اقرأ سبب عدم وجود صفقة.
5. بعد إغلاق الصفقة سجّل نتيجتها برقم التذكرة:

```
/result 7 win 2.00
```

## الأوامر

```
/trade
```

يقرأ اللقطات، يحلل كل شارت، يطبّق بوابات ثابتة، يحسب الحجم بالسكربت، ثم يعطي تذكرة واحدة لكل رمز أو يقول: لا صفقة.

```
/account
```

يحدّث ملفي البيانات ويعرض القيم قبل التحديث وبعده.

```
/result
```

يسجّل نتيجة تذكرة ويطبع الإحصاءات. أقل من ثلاثين صفقة مغلقة عيّنة أصغر من أن تدلّ على شيء.

```
/backtest
```

يعيد تشغيل القواعد الآلية على شموع صدّرتها بيدك من المنصة، ويقارن النتيجة برمي عملة. يختبر هيكل القواعد فقط، لا قراءة النموذج للشارت، ونتيجة الماضي ليست وعداً.

## الأخبار

الشارت لا يُظهر المواعيد. لذلك يفحص الأمر الأول الأخبار قبل التذكرة: من لقطة التقويم الاقتصادي إن أرفقتها، ومن بحث الويب داخل كلود كود فقط. الخبر يمنع التذكرة أو يضيف تحذيراً، ولا يصنع صفقة ولا يعطي سعراً. خبر مهم خلال ساعتين يعني: لا صفقة.

## القواعد الثابتة

- لا خدمات خارجية ولا مفاتيح. المدخلات هي لقطاتك والأرقام التي تكتبها والشموع التي تصدّرها بيدك. الاستثناء الوحيد: بحث الويب عن مواعيد الأخبار داخل كلود كود، ولا يُستعمل لأي سعر.
- لا يضع المشروع أي أمر ولا يعدّله ولا يغلقه. أنت من يُدخل كل أمر بيدك.
- «لا صفقة» نتيجة صحيحة. لا تُرفع نسبة المخاطرة لإخراج تذكرة، ولا وعد بالربح.
- نِسَب السيناريوهات تقديرات وليست إحصاءات مقيسة.
- كل جواب يفصل الدليل (ما قُرئ من اللقطات وما حسبه السكربت) عن الرأي.
- الرقم الذي لا يُقرأ في اللقطة لا يُخمَّن، بل يُقال إنه ناقص.

## الصفحة

اسم التطبيق:

```
AUREL
```

نفس المكتب في صفحة واحدة تعمل خارج الجلسة: ترفع صور الشارت أو تكتب الأرقام بيدك، فتحصل على تذكرة بزر نسخ، أو على جواب: لا صفقة، مع السبب. فيها سجل للنتائج.

- الصفحة لا تضع أي أمر، ولا تطلب كلمة مرور، ولا تحمّل شيئاً من الشبكة.
- التحليل بالصور يقرأ ملفات المهارات نفسها كلمة بكلمة في كل مرة، والصفحة تعرض الملفات التي تحملها.
- حاسبة الصفحة منقولة عن حاسبة المشروع، والاختبارات تقارن بينهما رقماً برقم.
- التحليل بالصور يعمل عند فتح الصفحة المنشورة من داخل تطبيق كلود. الحاسبة اليدوية تعمل في كل الأحوال.
- قبل كل تذكرة: قراءة ثانية مستقلة للصور، وفحص آلي لما كتبه التحليل، وقفل الأخبار، وحد الخسائر اليومي.
- التذكرة الأقدم من عشر دقائق تُفحص بالسعر الحالي قبل استعمالها.
- السجل يحفظ تقرير التحليل مع كل تذكرة، ويقبل مراجعة الصفقة بصورة بعد إغلاقها.

الأيقونة وملفات التثبيت كتطبيق على الهاتف موجودة في المجلد نفسه. التثبيت يعمل فقط عند استضافة المجلد على عنوان مستقل، وهناك تعمل الأرقام اليدوية والسجل دون التحليل بالصور.

```
ui/icons/
ui/manifest.json
ui/sw.js
```

الملف المبني:

```
ui/index.html
```

بعد تغيير أي مهارة أو أي ملف داخل المجلد، أعد البناء ثم شغّل الاختبارات ثم أعد نشر الصفحة:

```
python3 ui/build.py
python3 -m unittest discover -s tests -v
```

الصفحة المنشورة تبقى على ملفات المهارات القديمة إلى أن يُعاد نشرها.
